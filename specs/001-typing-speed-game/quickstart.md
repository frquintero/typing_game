# Quickstart: Typing Speed Game

**Feature**: Typing Speed Game
**Date**: October 16, 2025

## Prerequisites

- Node.js 18+
- npm or yarn

## Setup

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Open http://localhost:3000 in your browser

## First Game

1. Select time limit (15s, 30s, 60s)
2. Choose difficulty level (easy, medium, hard)
3. Pick a theme (normal, programming, motivational, fitness)
4. Click "Start Game"
5. Type the displayed text as quickly and accurately as possible
6. View your results and try again

## Features to Test

- Real-time WPM and accuracy display
- Color-coded feedback (green correct, red errors, yellow current word)
- Leaderboard submission
- Focus Mode (no timer)
- Power-up unlock after 3 perfect games
- Dark/light mode toggle
- Mobile responsiveness

## Development

- Run tests: `npm test`
- Build for production: `npm run build`
- Lint code: `npm run lint`
